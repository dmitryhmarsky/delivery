# Доставка (прототип)

Игра про доставку грузов от первого лица. Ты сам загружаешь фургон, планируешь маршрут и развозишь посылки.
Если сложил их неправильно, придётся разбирать кузов на ходу. Груз ломается, пока ты его несёшь, а у каждого дома свои помехи.
Написано на Python + [Ursina](https://www.ursinaengine.org/). Графика процедурная (low-poly, текстуры генерируются кодом), ничего скачивать не нужно.

## Запуск

**Windows:** двойной клик по `run.bat`. При первом запуске он сам создаст окружение и поставит Ursina (нужен установленный Python 3.10+ с галочкой Add to PATH).

Вручную:

```bash
pip install -r requirements.txt
python main.py
```

Если картинка плоская и хочется освещения: `python main.py --lit` (зависит от видеокарты).
Текстуры создаются сами при первом запуске. Пересоздать вручную: `python tools/make_textures.py`.

## Как проходит день

1. **Загрузка.** 6 посылок лежат на земле за фургоном. Подними посылку (**G**), подойди к задней двери и нажми **E**: она ляжет в ряд кузова.
   В кузове два ряда по 4 места. Ряд работает как стопка: достать можно только то, что лежит ближе к двери, то есть **положил последним, достанешь первым**.
   В какой ряд ляжет посылка, зависит от того, с какой стороны от оси фургона ты стоишь (слева или справа).
2. **Маршрут.** Когда всё в кузове, нажми **P**. Открывается карта улицы: кликай по домам в том порядке, в каком поедешь.
   Планировщик показывает длину пути, время на маршрут и **сколько посылок придётся вынимать, чтобы добраться до нужных**.
   Маршрут можно подогнать под то, как ты загрузил, а можно перегрузить кузов заново и спланировать лучше.
3. **Езда.** Сядь в кабину (**E** у передней двери). **W** газ, **S** тормоз, **A/D** сместиться по дороге, **X** разворот на месте, **E** выйти.
   Резкое торможение на скорости бьёт посылки в кузове (хрупкие страдают сильнее).
4. **Выгрузка.** Подойди к задней двери и достань посылку (**E**). Нужная лежит глубоко? Вынимай мешающие и бросай их на землю (**G**), потом достань нужную, неси к двери дома (**E**), а потом возвращай остальные в кузов.
   Вручать посылки нужно строго по маршруту. Изменить маршрут можно в любой момент (**P**), пока ты не за рулём.
5. **Итоги дня.** Заработок, время, разбитые посылки и число лишних перекладываний. **N** начинает новый день.

Оплата зависит от целостности посылки, типа груза, расстояния и от того, уложился ли ты во время маршрута. Безупречная доставка (98%+) даёт +25%. Разбитая посылка это штраф $20.

## Управление

| Клавиша | Действие |
|---|---|
| WASD + мышь | ходить, осматриваться |
| Shift | бег (трясёт груз в руках) |
| C (держать) | идти осторожно |
| Space | прыжок (приземление бьёт груз) |
| E | положить/достать у задней двери, вручить у двери дома, сесть за руль/выйти |
| G | поднять посылку с земли / бросить на землю |
| P | загрузили, пора планировать маршрут (или изменить его в пути) |
| F | бросить кость собаке |
| X | развернуть фургон (за рулём, когда стоишь) |
| R | телепорт к задней двери фургона |
| Esc | выход (в планировщике отмена) |

## Препятствия у домов

У каждого дома свой набор (перемешивается при каждом запуске). Дома отличаются цветом: посылки и столбики у калиток раскрашены под свой дом.

- **Собака**: замечает тебя во дворе и гонится быстрее ходьбы. Брось кость (**F**), и она отвлечётся на 6 секунд. Укус бьёт груз.
- **Узкий проход**: коридор между кустами. Быстрая ходьба бьёт груз о стены, проходи с **C**.
- **Поливалка**: включается и выключается по таймеру. Вода портит груз, пережди или обойди.

Типы груза: посылка (прочная), торт, стекло (самое хрупкое, но платят больше). Тип виден по цвету крышки коробки.

## Структура

```
main.py             запуск
game/logic.py       чистая логика: урон, оплата, ряды кузова, оценка возни, маршрут (без движка, есть тесты)
game/game.py        игровой цикл: фазы дня, вождение, перенос, HUD
game/planner.py     экран планирования маршрута
game/world.py       улица, дома, заборы, фургон с открытым кузовом
game/obstacles.py   собака и поливалка
game/textures.py    процедурные текстуры
tests/              python tests/test_logic.py
```

`game/logic.py` специально не зависит от Ursina: его можно почти один в один перенести на Rust (Bevy), если проект вырастет.

## Идеи на дальше

- модели Kenney / Quaternius вместо кубиков (GLB подключаются в `world.py`)
- разные размеры посылок (большая занимает два места), тяжёлые вниз
- больше препятствий: недовольный жилец, дом без номера, скользкий пол после дождя
- улучшения (больший кузов, ремни, тележка), погода, ночь
- кооператив: один за рулём, второй раскладывает груз
