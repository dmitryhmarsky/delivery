# Доставка (прототип)

Игра про доставку грузов от первого лица. Груз ломается, пока ты его несёшь, а у каждого дома свои помехи.
Написано на Python + [Ursina](https://www.ursinaengine.org/). Графика процедурная (low-poly, текстуры генерируются кодом), ничего скачивать не нужно.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Если картинка плоская и хочется освещения: `python main.py --lit` (зависит от видеокарты).
Текстуры создаются сами при первом запуске. Пересоздать вручную: `python tools/make_textures.py`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD + мышь | ходить, осматриваться |
| Shift | бег (трясёт груз!) |
| C (держать) | идти осторожно |
| Space | прыжок (приземление бьёт груз) |
| E | взять груз у фургона / вручить у двери / пополнить кости |
| F | бросить кость собаке |
| R | вернуться к фургону |
| Esc | выход |

## Как играть

1. Подойди к белому фургону и нажми **E**, чтобы взять груз.
2. Найди дом с жёлтым лучом над ним и донеси груз до двери.
3. Следи за **целостностью груза**: оплата зависит от неё, от срока и от типа груза. Безупречная доставка (98%+) даёт +25%.
4. Если груз разбит, штраф $20.

## Препятствия у домов

У каждого дома свой набор (перемешивается при каждом запуске):

- **Собака**: замечает тебя во дворе и гонится быстрее ходьбы. Брось кость (**F**), и она отвлечётся на 6 секунд. Укус бьёт груз.
- **Узкий проход**: коридор между кустами. Быстрая ходьба бьёт груз о стены, проходи с **C**.
- **Поливалка**: включается и выключается по таймеру. Вода портит груз, пережди или обойди.

Типы груза: посылка (прочная), торт, стекло (самое хрупкое, но платят больше).

## Структура

```
main.py             запуск
game/logic.py       чистая логика: урон, оплата, заказы (без движка, есть тесты)
game/world.py       улица, дома, заборы, фургон
game/obstacles.py   собака и поливалка
game/game.py        игровой цикл, HUD
game/textures.py    процедурные текстуры
tests/              python tests/test_logic.py
```

`game/logic.py` специально не зависит от Ursina: его можно почти один в один перенести на Rust (Bevy), если проект вырастет.
